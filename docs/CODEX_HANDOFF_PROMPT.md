# Opening message for Codex

请你作为这个仓库的主开发代理，直接开始搭建一个桌面端序列图工具。目标用户优先是游戏特效师。请严格阅读仓库里的 `docs/PROJECT_REQUIREMENTS.md` 和 `.codex/skills/sprite-sheet-desktop/SKILL.md`，按其中定义的产品范围、技术方向和交付规则执行。推荐技术栈为 Electron + React + TypeScript；如果仓库尚未初始化，请直接完成工程初始化与目录搭建。

本项目必须支持：单张序列图导入与自动网格识别播放、多图/文件夹导入、帧排序、预览播放、FPS/起止帧/跳帧/反转、序列图拆分与合并、GIF 导入导出、所有帧统一旋转、撤销重做，以及导出图片序列/序列图/GIF。对于单张规则序列图（例如 6x6、8x8），需要尽量自动识别并直接开始播放，同时保留手动覆盖能力。

请你自己建立完整工程目录，自己安装所需依赖，自己补充必要配置，并且在每次阶段性交付前必须执行自检：至少检查 typecheck、lint、test、build（若已配置），并确认没有乱码或明显错误；然后明确说明你检查了什么、结果如何、还有哪些未覆盖风险。不要只给计划，直接开始实现，先完成最小可运行版本，再逐步扩展功能。
