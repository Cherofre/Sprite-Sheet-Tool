# Sprite Sheet Tool v1.0.4

## 本次更新
- 新增首次安装和更新后首次打开的操作说明弹窗，集中说明导入、右键入口、Photoshop 往返和快捷键。
- 新增启动后的更新提醒卡片，区分安装版和便携版，并支持“稍后”与“这个版本不再提醒”。
- 设置中新增“启动或更新后自动显示操作说明”开关，方便关闭后再恢复。
- 优化说明弹窗布局：左侧导航固定，右侧内容独立滚动，快捷键页不再把整个窗口拉得过大。
- 优化说明页与设置页右上角关闭按钮的位置，滚动内容时按钮保持固定。

## 推荐下载
- 安装版：`Sprite-Sheet-Tool-1.0.4-setup.exe`
- 便携版：`Sprite-Sheet-Tool-1.0.4-portable-dir.zip`

## 更新说明
- 安装版支持应用内检查更新，下载完成后会提示“重启并安装”。
- 便携版支持检查到新版本后打开下载页，仍然采用手动覆盖更新。
- 如果 GitHub Release 或更新源不可公开访问，应用内检查更新仍可能受到访问限制。
